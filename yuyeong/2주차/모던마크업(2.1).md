# 2week _ javascript 기본

### 2.1
### 모던 마크업
----

-  type 속성:`<script type=…>`
HTML4에선 스크립트에 type을 명시하는 것이 필수였다. 따라서 type="text/javascript" 속성이 붙은 스크립트를 어렵지 않게 찾을 수 있었다. 
    > 이젠 타입 명시가 필수가 아니다. 

- language 속성: `<script language=…>`
이 속성은 현재 사용하고 있는 스크립트 언어를 나타낸다.
    >현재 js 가 기본 언어이므로 사용할 필요가 없어졌다.

-----
### 외부 스크립트
자바스크립트 코드의 양이 많은 경우엔, 아래처럼 파일을 소분해 저장할 수 있었다.
`<script src="/path/to/script.js"></script>`
- 여기서 해당 루트는 파일이 위피한 절대 경로를 나타낸다. 

또한, 복수의 스크립트를 html에 삽입하고 싶다면, 스크립트 태그를 여러개 사용하면 된다.

> HTML 안에 직접 스크립트를 작성하는 방식은 대개 스크립트가 아주 간단할 때만 사용합니다. 스크립트가 길어지면 별개의 분리된 파일로 만들어 저장하는 것이 좋습니다.

> 스크립트를 별도의 파일에 작성하면 브라우저가 스크립트를 다운받아 캐시(cache)에 저장하기 때문에, 성능상의 이점이 있습니다.

### 요약

웹 페이지에 자바스크립트 코드를 추가하기 위해 `<script>` 태그를 사용합니다.

type 과 language 속성은 필수가 아닙니다.

외부 스크립트 파일은 `<script src="path/to/script.js"></script>`와 같이 삽입합니다
